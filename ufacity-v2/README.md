# Ufacity V2

Чистый Godot 4.7.2 проект. Старый прототип (`../client`, `../server`) не тронут и остаётся эталоном для аудита.

## Слои (зависимость только сверху вниз)

| Папка | Назначение | Правило |
|---|---|---|
| `core/` | Боевая симуляция, данные героев, лог боя | Только `RefCounted`/`Resource`. Без Node, без сцены, без времени кадра. Детерминирована по seed. |
| `data/` | Определения героев/скиллов (`.tres`/`.json`) | Данные, не код. |
| `view/` | Арена, камера, HeroView, проигрывание лога | Читает лог из `core/`. Никогда не меняет результат боя. |
| `ui/` | HP-бары, таймер, переключатель скорости | Только отображение + сигналы. |
| `assets/` | GLB, текстуры (после аудита) | Исходники не переписываются. |
| `tests/` | Headless-тесты (`godot --headless -s`) | Запуск: `tests/run_all.sh`. |

## Ключевые решения

1. **Симуляция отделена от показа.** `core/BattleSim.run(seed, teams) -> BattleLog` считает весь бой за один вызов на фиксированном тике 0.1 с, максимум 90 с (900 тиков). Результат — список событий с `t` (в секундах боя).
2. **Скорость x1/x2/x3 меняет только `playback_speed`** проигрывателя (и `AnimationPlayer.speed_scale`). Лог и итог не зависят от скорости — это проверяется тестом.
3. **Урон привязан к маркеру удара.** Событие `hit` имеет `t_impact`; проигрыватель стартует клип атаки в `t_impact - impact_offset(clip)/speed`, так что урон и удар совпадают.
4. **Сервер авторитетен.** Тот же `BattleSim` портируется/сверяется с серверной версией; клиент в онлайне показывает лог с сервера. Клиентский расчёт — только для офлайн-превью.
5. **Построение:** 2 передняя линия + 3 задняя на каждую сторону; позиции — из `Marker3D`-слотов арены, не из кода.

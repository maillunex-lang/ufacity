# Ufacity V2

Коллекционная Idle RPG в стиле классической AFK Arena: **2.5D бой на 2D-спрайтах**, герои — предрендеренные 3D-модели. Godot 4.7.2, Android, вертикаль. Старый прототип (`../client`, `../server`) не тронут.

## Два проекта Godot в одной папке

| Папка | Назначение | Попадает в APK |
|---|---|---|
| `art_src/` | **Исходники и конвейер.** GLB героев (LFS), рендерер `render/render_hero.gd`. Свой `project.godot`, поэтому игровой проект его не импортирует. | нет |
| корень (`project.godot`) | **Игра.** Только 2D: `AnimatedSprite2D`, фоны, UI, симуляция. GLB здесь нет. | да |

## Конвейер ассетов

```
art_src/heroes/<hero>.glb ──tools/render_hero.sh──▶ assets/sprites/<hero>/<hero>_N.png + <hero>.json
   (копия оригинала)        Godot + Xvfb, ортокамера,      (атлас, обрезанные кадры,        │
                            прозрачный SubViewport          метаданные)                     ▼
                                                      view2d/hero_sprite.gd → AnimatedSprite2D
```

Правила рендера (запечены в JSON, игра ничего не угадывает):
- одна фиксированная ортокамера: pitch 18° сверху, герой развёрнут на 3/4 к камере, смотрит **вправо**; команда B = `flip_h` (зеркало);
- одинаковый масштаб для всех героев (`ppm` = 128 пикс/м), одна точка опоры `pivot` (между ступнями) во всех кадрах;
- прозрачный фон (`SubViewport.transparent_bg`), MSAA 4x; три источника света (основной, заполняющий, контровой);
- корневое движение бёдер вырезано (герой стоит на месте; движение даёт код), кроме `death`;
- кадр не должен касаться границы холста (оружие/плащ не обрезаются): иначе рендер падает с ошибкой;
- длительность клипа сохраняется: у каждого клипа свой эффективный FPS = кадры / длина оригинала;
- пустые роли фиксируются в `missing_roles`, **подмена другими клипами запрещена** без согласования.

Запуск: `ufacity-v2/tools/render_hero.sh swordsman --fps=15` (5 с на героя, нужен `xvfb-run`), затем `godot --headless --path ufacity-v2 --import`.
Тест: `godot --headless --path ufacity-v2 -s tests/test_sprite_atlas.gd -- swordsman`.

## Слои игры (зависимость сверху вниз)

| Папка | Назначение | Правило |
|---|---|---|
| `core/` | Боевая симуляция, лог боя | `RefCounted`, без Node, детерминирована по seed. |
| `data/` | Герои, скиллы | Данные, не код. |
| `view2d/` | Арена 2.5D, `HeroSprite`, проигрыватель лога | Читает лог, никогда не меняет результат. |
| `ui/` | HP, таймер, скорость | Отображение + сигналы. |
| `assets/` | Атласы, фоны, UI-арт | Только готовые к отгрузке ресурсы. |
| `tools/` | Скрипты конвейера | — |
| `tests/` | Headless-тесты | — |

# HTTP из Godot

`HTTPRequest`, HTTPS, JSON.
Не ENet и не самописный мультиплеер: боя в реальном времени нет.

Токен сессии хранить локально, не в репозитории и не в строке запроса.
UI ждёт ответ и показывает ошибку сети.
Награду на экране брать только из ответа сервера.

Таймаут и один повтор на GET.
POST призыва и награды не повторять вслепую, чтобы не было двойной выдачи.
Если сервер принял запрос, а ответ потерялся, повтор идёт с тем же ключом идемпотентности.

Базовый URL один, через проектную настройку.
Локальный сервер и VPS переключаются этой настройкой, не правкой кода.

Выход: один клиентский скрипт запросов и какие сигналы он шлёт UI.

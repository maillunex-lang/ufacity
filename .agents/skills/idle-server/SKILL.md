# Сервер idle-игры

Один процесс API и Postgres. Без микросервисов и без очередей.
Клиенту не верить. Он шлёт id стадии и состав из 5 id.
Сервер сам грузит статы, прогоняет тот же бой с seed и только потом выдаёт награду.
Один и тот же seed и те же статы дают тот же лог, что и скилл `auto-battle`.

Айдл-награда считается от времени последнего сбора на сервере. Есть потолок часов.
Призыв крутит сервер. Шансы и pity в базе. Ответ — кого выдали.
Клиент не присылает редкость и не присылает золото.

Аккаунт: почта или логин, пароль только хеш.
Сессия: случайный токен со сроком, не вечный jwt без срока.
Ручки узкие: регистрация, логин, профиль, старт стадии, сбор айдла, призыв.
Нет ручки «добавь золото».
Призыв и сбор не чаще разумного интервала. POST не должен выдавать награду дважды при повторе.

Postgres не торчит в интернет. Секреты только в окружении, не в репозитории.

Выход: схема таблиц, список ручек и что проверяет каждая.

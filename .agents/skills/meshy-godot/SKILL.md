# Meshy в Godot

Экспорт из Meshy: один GLB. Меш, риг, текстуры и клипы внутри.
Не OBJ и не STL. FBX только если GLB пришёл без скелета.
Перед авторигом, если ноги или руки слиплись, сначала remesh.
Плагин Meshy годится для черновика. В репозиторий класть скачанный GLB, не зависимость от моста.

Клипы у каждого героя строго: `idle`, `attack`, `skill`, `hit`, `death`.
Лишние имена переименовать под этот набор.
`idle` зациклен. `attack`, `skill` и `hit` один раз. `death` держит последний кадр.
Без клипа ходьбы и без root motion. Герой не двигается с маркера.

Файл: `client/assets/heroes/<id>.glb`, в git через Git LFS.
Сцена героя: корень `Node3D`, внутри экземпляр GLB.
Масштаб и поворот только на корне, чтобы ноги были на Y=0 и лицо смотрело в +Z.
Левая сторона поворачивается на 180 градусов родителем, не правкой GLB.

Скрипт вида героя играет клип по событию из лога боя.
Если клипа нет, оставаться в `idle` и писать предупреждение, не падать.
Один герой: до 30 тысяч треугольников, текстура 1024. На слабом телефоне 512.
В кадре десять моделей одновременно.

Не звать API Meshy из игры и не коммитить ключ.
Не тащить чужие модели из галереи Meshy в релиз без права на использование.

Выход: дерево сцены героя, таблица клипов и как событие боя включает `AnimationPlayer`.

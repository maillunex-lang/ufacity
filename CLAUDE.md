# Ufacity

Idle 3D-арена 5 на 5. Клиент на Godot 4, API на своём VPS.

## Где код

- `client/` — Godot. Сцены, скрипты, GLB героев.
- `server/` — один API и Postgres. Снаружи его видно только через nginx.
- `.claude/skills/` — скиллы Claude Code. Подгружаются по задаче, не все сразу.

## Правила, которые действуют всегда

- Бой считается данными с seed. Сцена только проигрывает лог на маркерах.
- Золото, призыв, айдл-награда и победа стадии выдаются только сервером. Клиенту эти числа не верят.
- Герои из Meshy: один GLB на героя, клипы `idle`, `attack`, `skill`, `hit`, `death`.
- Не коммитить `.env`, ключи TLS, ключ подписи Android и ключ Meshy.
- Не копировать имена, скиллы и арт чужих игр.

## Как звать скиллы

`/skills` показывает список. Точечно: `/auto-battle`, `/meshy-godot`, `/idle-server`.

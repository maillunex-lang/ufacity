# Ufacity

Idle 3D-арена 5 на 5. Клиент на Godot 4, API на своём VPS.

Это те же правила, что в AGENTS.md. Меняй оба файла вместе.

## Где код

- `client/` — Godot. Сцены, скрипты, GLB героев.
- `server/` — один API и Postgres. Снаружи его видно только через nginx.
- `.claude/skills/` — скиллы Claude Code. Те же тексты, что в `.agents/skills/`.

## Правила, которые действуют всегда

- Бой считается данными с seed. Сцена только проигрывает лог на маркерах.
- Золото, призыв, айдл-награда и победа стадии выдаются только сервером. Клиенту эти числа не верят.
- Герои из Meshy: один GLB на героя, клипы `idle`, `attack`, `skill`, `hit`, `death`.
- Не коммитить `.env`, ключи TLS, ключ подписи Android и ключ Meshy.
- Не копировать имена, скиллы и арт чужих игр.

## Как звать скиллы

`/skills` показывает список. Точечно: `/auto-battle`, `/meshy-godot`, `/idle-server`.
Если меняешь скилл, правь тот же текст в `.agents/skills/<имя>/SKILL.md`.

## Работа через Claude Remote на VPS

- Основной способ разработки: Claude Code Remote Control с Android.
- Работать под пользователем gamedev.
- VPS содержит другие проекты: не изменять их файлы, службы и настройки.
- Не менять Nginx, SSH, firewall, DNS и занятые порты без разрешения.
- Не использовать root или sudo без отдельного подтверждения.
- Не запускать обновления ОС и системные установки самостоятельно.
- Перед изменениями проверять Git-ветку и незакоммиченные файлы.
- Выполнять задачи небольшими проверяемыми этапами.
- Не запускать параллельные изменения в общей рабочей папке.
- Не удалять и не перезаписывать исходные GLB.
- Для оружия использовать BoneAttachment3D и проверять анимации.
- Проверять доступность Godot MCP, не считать его подключённым без проверки.
- После изменений запускать доступные тесты Godot.
- По возможности делать скриншоты сцен через Xvfb.
- Не считать сборку APK успешной без проверки созданного файла.
- Не выполнять push, merge и развёртывание без разрешения.
- Не раскрывать секреты и токены в отчётах.
- Перед ресурсоёмкими операциями проверять нагрузку VPS.

# Герои

Сюда кладётся `client/assets/heroes/<id>.glb` из Meshy, одним файлом.

Пока файлов нет. Сцена боя рисует капсулы с подписью TEMP. Это не финальные модели и не проверенный импорт Meshy.

Ожидаемые клипы, когда GLB появится: `idle`, `attack`, `skill`, `hit`, `death`. Для ближнего боя дополнительно `move`, если скелет его содержит. Нет клипа `move` — боец всё равно едет по событию лога, без root motion.

# Модели и анимации

Источник персонажей: Meshy. В игру и в git кладётся скачанный GLB одним файлом, не ключ API и не чужая модель из галереи без права на использование.

Путь: `client/assets/heroes/<id>.glb`. Крупные GLB, FBX и звук уже помечены в `.gitattributes` для Git LFS.

Пока GLB нет. Импортёр боя не зашит в конкретный файл: сцена читает лог и ищет бойца по id. Временные капсулы подписаны TEMP. Это не проверка Meshy.

Когда файл появится, руками в Godot проверить и записать сюда:

- есть ли скелет
- имена клипов: `idle`, `attack`, `skill`, `hit`, `death`, для ближних желателен `move`
- масштаб, ноги на Y=0, лицо в +Z
- материалы после импорта
- можно ли проиграть клип одной модели на скелете другой

Несовместимый скелет не считать общим набором анимаций.

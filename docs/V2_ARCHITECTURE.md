# Ufacity V2 — архитектура (2.5D, спрайты)

Утверждено заказчиком: стиль AFK Arena. **В бою нет 3D-сцены и нет GLB.** Герои — 3D-модели, предрендеренные в 2D-атласы.

## Принципы
1. Бой считается данными: `core/BattleSim.run(seed, teams) → BattleLog`, тик 0,1 с, максимум 90 с. Без Node.
2. `view2d/` только проигрывает лог. Скорость x1/x2/x3 меняет `speed_scale` проигрывателя и `AnimatedSprite2D`, не расчёт.
3. Золото, призыв, награды, победа — только сервер. Клиентский расчёт боя — офлайн-превью; в онлайне показывается лог сервера.
4. Урон совпадает с ударом: у каждого клипа в атласе будет маркер кадра удара (`impact_frame`, этап E), проигрыватель запускает клип так, чтобы кадр удара пришёлся на `t_impact` лога.
5. Камера боя фиксированная; перспектива запечена в рендере героев и в слоях фона.

## Сцена боя (2D, 720×1280)
```
Battle (Node2D)
 ├─ Background        ParallaxBackground / Parallax2D: 3–5 слоёв (небо, дальний план, декор, пол, передний план)
 ├─ Floor markers     10 Marker2D: A_F0..1, A_B0..2, B_F0..1, B_B0..2 (положение даёт глубину: задний ряд выше и меньше)
 ├─ Units (Y-sort)    HeroSprite ×10 (AnimatedSprite2D), масштаб по ряду, тень-«пятно»
 ├─ Effects           частицы/спрайт-эффекты попаданий и скиллов
 └─ UI (CanvasLayer)  HP, таймер, скорость, кнопки ультов
```
Глубина (2.5D): передний ряд ниже по экрану и крупнее (`scale` ≈ 1.0), задний выше и мельче (≈ 0.85); `y_sort_enabled`.

## Конвейер ассетов
GLB (`art_src/heroes`, копия, оригиналы в `client/` не трогаем) → отбор клипов по ролям (`art_src/hero_assets.json`) → вырезание root motion → рендер кадров ортокамерой в прозрачный SubViewport → обрезка по альфе, shelf-упаковка в страницы ≤ 2048 → JSON (кадры, margin, pivot, эффективный FPS, `loop`, `missing_roles`) → импорт Godot (VRAM-сжатие ETC2/ASTC) → `HeroSprite` строит `SpriteFrames` из `AtlasTexture` с `margin`.

Роли: `idle`, `run`, `attack`, `hit`, `skill`, `death`. Нет клипа → роль в `missing_roles`, никаких подмен.

## Бюджет размера (цель APK ≤ 95 МБ)
- Измерено на прототипе: мечник, 5 ролей, 173 кадра @ 15 FPS, 128 пикс/м → атлас 2048×1896, **3,9 МБ** в APK (ETC2) и **3,9 МБ** видеопамяти (несжатый 15,5 МБ).
- Герой со всеми 6 ролями ≈ 4,5 МБ. 20 героев ≈ 90 МБ — не помещаются вместе с остальным: базовые герои в APK, остальные грузятся отдельно (PCK/DLC с сервера, пакеты по героям).
- Рычаги: FPS 12–15, ppm 112, отбрасывание дублей кадров, общий атлас эффектов.

## Что хранится где
- В git: GLB (LFS), скрипты конвейера, готовые атласы + JSON, тесты.
- Не в git: `.godot/`, извлечённые из GLB текстуры, промежуточные кадры (`/tmp/v2_frames`).

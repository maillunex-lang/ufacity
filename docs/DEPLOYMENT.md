## Когда появится доступ

1. Снять резервную копию только того vhost, который собираемся менять. Не делать `docker compose down` по всей машине и не чистить чужие тома.
2. Найти, почему `/LunexGame/` уже даёт 502. Не занимать чужой порт.
3. Поднять игру отдельным compose-проектом, со своей сетью и томом Postgres. Наружу новый порт не публиковать, пока reverse proxy не проверен.
4. В proxy добавить или починить один location на уже живущий API. Проверка: `GET /LunexGame/health` возвращает `{"ok": true, "service": "ufacity"}`.
5. Если проверка не сошлась, вернуть резервную копию vhost. Игру откатить своим compose, не чужим.

Секреты остаются на сервере и в GitHub Secrets. В репозиторий не класть.

Локально, без VPS:

```bash
cd server
python -m pip install -r requirements.txt
PYTHONPATH=. uvicorn app.main:app --host 127.0.0.1 --port 8080
curl -s http://127.0.0.1:8080/LunexGame/health
```

Этот локальный запуск на VPS не выполнялся.
